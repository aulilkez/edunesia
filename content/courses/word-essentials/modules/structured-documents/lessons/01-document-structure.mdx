# Structure a Word Document

A well-structured document uses built-in heading styles to show how ideas relate. Apply **Heading 1** to a main section and **Heading 2** to a subsection. Keep ordinary text in the **Normal** style.

The Navigation pane uses heading styles to build an outline, so readers can move between sections without searching the whole file. The same structure can help screen-reader users understand and navigate a long document.

<Callout type="info">
  Choose a heading style from the Styles gallery instead of changing font size and boldness alone.
  Visual formatting can look like a heading without carrying the same document structure.
</Callout>

## A simple outline

1. Add a descriptive document title.
2. Use Heading 1 for each main section.
3. Use Heading 2 for sections nested under a main section.
4. Keep paragraphs focused and use lists for grouped steps or items.

When the outline changes, update heading levels rather than adding spaces or blank paragraphs to force the page layout.
