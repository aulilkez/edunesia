# Your First Go Program

A small Go command-line program declares its package, imports what it uses, and starts in `main`:

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Edunesia!")
}
```

`fmt` is a standard-library package for formatted input and output. The import makes the package available under the name `fmt`, and `fmt.Println` writes a line to standard output.

<Callout type="info">
  Go's formatter is part of its everyday workflow. Running `gofmt` on source files applies the
  language's standard formatting rules.
</Callout>

Save this as `main.go`. With Go installed, run it from the same directory using `go run main.go`.
