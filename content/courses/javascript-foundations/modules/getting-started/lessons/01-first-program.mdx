# Your First JavaScript Program

JavaScript programs are made of instructions that a runtime executes. Start with a statement that writes a message:

```javascript
console.log("Hello, Edunesia!");
```

<Callout type="info">
  `console.log` is useful while learning and debugging. It writes a value to the runtime's console.
</Callout>
