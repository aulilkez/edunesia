# Your First Python Program

Python runs statements from top to bottom. The `print` function displays a value:

```python
course = "Python Foundations"
print("Hello, Edunesia!")
print(course)
```

The assignment binds the name `course` to a string. The second call to `print` looks up that name and displays its value.

<Callout type="info">
  Save the example in a file such as `main.py`, then run it with `python main.py` in a terminal
  where Python is installed.
</Callout>

Python uses indentation to group the body of functions and other blocks. This first script has no block, so each statement begins at the left edge.
