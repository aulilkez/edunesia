## Declaring a variable

Use `const` when a binding should not be reassigned, and `let` when it should.

```js title="greeting.js"
const greeting = "Hello";
let visits = 0;

visits += 1;
console.log(greeting, visits);
```

| Keyword | Reassignable | Typical use          |
| ------- | ------------ | -------------------- |
| `const` | No           | Default choice       |
| `let`   | Yes          | A value that changes |

<Tip title="Prefer const">
  Start with `const`. Change to `let` only when reassignment is needed.
</Tip>
