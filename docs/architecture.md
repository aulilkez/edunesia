# Source architecture

The root application is a single Bun/Vite+ and TanStack Start app. The source
tree separates file-based routing, domain features, shared browser-safe code,
and server-only infrastructure.

```text
src/
├── routes/       URL definitions, loaders, metadata, and feature composition
├── features/     content, learning, and community domain code
├── components/   shared Shadcn UI
├── hooks/        shared browser hooks
├── lib/          environment, query/tRPC client, and browser-safe utilities
├── server/       database, migrations, tRPC server, and server logger
└── styles/       global CSS entry, themes, and tokens
```

`src/routeTree.gen.ts` is generated by TanStack Router and must not be edited.
Content Collections output under `.content-collections/` is generated as well.

## Dependency map

| Kind              | Current modules                                                                                                    |
| ----------------- | ------------------------------------------------------------------------------------------------------------------ |
| Server-only       | `src/server/**`, `src/lib/env/server.ts`, `src/server/db/migrate.ts`                                               |
| Browser/client    | `src/features/*/pages/**`, feature UI, `src/components/**`, `src/hooks/**`, `src/lib/logger.ts`, `src/lib/trpc.ts` |
| Universal         | Content schemas and queries, shared types, `src/lib/query.ts`, `src/lib/utils.ts`                                  |
| Domain-specific   | `src/features/content`, `src/features/learning`, `src/features/community`                                          |
| Framework-managed | `src/routes/**`, `src/routeTree.gen.ts`, `.content-collections/**`                                                 |
| Root integrations | `content-collections.ts`, `drizzle.config.ts`, `vite.config.ts`, `evlog.config.ts`                                 |

`src/lib/trpc.ts` retains the existing isomorphic tRPC adapter: local server
calls use the app router and browser calls use `/api/trpc`. The router, context,
procedures, middleware, query client, and SSR query integration were not
redesigned.

## File migration

| Previous location                                            | Current location                       |
| ------------------------------------------------------------ | -------------------------------------- |
| `src/db/**`                                                  | `src/server/db/**`                     |
| `src/lib/server/db.ts`                                       | `src/server/db/connection.ts`          |
| `src/lib/server/logger.ts`                                   | `src/server/logger.ts`                 |
| `src/lib/server/trpc/**`                                     | `src/server/trpc/**`                   |
| `src/content/**`                                             | `src/features/content/**`              |
| `src/components/content/{chart-renderer,mdx-components}.tsx` | `src/features/content/components/**`   |
| `src/components/content/community-markdown*`                 | `src/features/community/components/**` |
| Course and lesson presentation in route files                | `src/features/learning/pages/**`       |

Database schema and migration behavior did not change. The auth and Lingui
folders were not created: this root app has no Better Auth or Lingui runtime.
See [server-client-boundaries.md](./server-client-boundaries.md) and
[feature-architecture.md](./feature-architecture.md) for contribution rules.
